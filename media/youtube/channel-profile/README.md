# Profil twórcy aplikacji — YouTube

Wygenerowano 3.11.2026 wbudowanym narzędziem image_gen. Grafiki przedstawiają ogólnie tworzenie aplikacji, bez marki outlineGo.

- `creator-banner-v1.png` — baner: szkic interfejsu przechodzący przez symbol kodu w gotową aplikację.
- `creator-avatar-v1.png` — awatar: telefon pomiędzy nawiasami kodu.

Przed publikacją sprawdzić kadrowanie w podglądzie YouTube Studio, szczególnie środkowy pas banera i okrągły kadr awatara.

## Pliki do wgrania

- `youtube-banner-2560x1440.png` — baner 2560 × 1440 px, eksport z wariantu v2.
- `youtube-avatar-800x800.png` — awatar 800 × 800 px.

Na prośbę użytkownika przygotowano docelowe formaty za pomocą skalowania bicubic w System.Drawing. Źródła zachowano. Zwiększenie wymiarów banera nie dodaje detali do wygenerowanego obrazu. Oba pliki zweryfikowano pod względem wymiarów i limitu wielkości pliku.
